# PRACTICAL 11 – MCMC and Bayesian Analysis of Sunspot Data

### Aim
To analyse historical sunspot data using the Metropolis-Hastings MCMC algorithm and estimate Gamma distribution parameters using Bayesian analysis.

### What I Did
1. Loaded and analysed monthly sunspot data from 1749 to 2018.
2. Divided the dataset into 23 groups of 12 years each.
3. Checked zero and positive sunspot observations.
4. Created time-series plots and histograms.
5. Applied the Gamma distribution to positive sunspot values.
6. Implemented the Metropolis-Hastings algorithm to estimate alpha and beta.
7. Removed burn-in samples and calculated posterior means and 95% credible intervals.
8. Compared estimated Gamma parameters and mean sunspot numbers across all 23 groups.
9. Created graphs to show changes in sunspot activity over time.

### Conclusion
In this practical, I learned how to use the Metropolis-Hastings MCMC algorithm for Bayesian parameter estimation. I successfully estimated Gamma distribution parameters and analysed changes in sunspot activity across different time periods.
