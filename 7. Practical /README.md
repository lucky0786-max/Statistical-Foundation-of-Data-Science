**Aim**

To perform statistical analysis, data visualization, data scaling and Principal Component Analysis (PCA) on the Wine dataset using Python.

**What I Did**

1. Loaded the Wine dataset using Scikit-learn.
2. Displayed basic statistical information using `describe()`.
3. Created boxplots to compare wine features across different classes.
4. Created a scatterplot using two variables (Alcohol and Malic Acid).
5. Calculated and visualized the covariance matrix using a heatmap.
6. Applied Standard Scaling to bring all features to a similar scale.
7. Applied PCA to reduce 13 features into 2 principal components and visualize class separation.

**Libraries Used**
Pandas & NumPy: Data handling and analysis.
Matplotlib & Seaborn:Data visualization.
Scikit-learn:Wine dataset, scaling and PCA.

**Conclusion**
In this practical, I learned how to analyse and visualize the Wine dataset using Python. 
I performed statistical analysis, calculated covariance, applied data scaling and used PCA to reduce dimensions. 
The PCA scatterplot helped visualize the separation between the three wine classes.
