**Aim**

To perform different statistical tests on the TeachingRatings dataset and analyse the relationship between gender, age,
tenure, beauty score and teaching evaluation using Python.

**Libraries Used**

Pandas: To load and analyse the dataset.
Matplotlib: To create graphs and visualizations.
SciPy:To perform statistical tests.

**What I Did** 

1. T-Test:Compared teaching evaluation scores of male and female teachers.
2. ANOVA Test: Compared beauty scores among three age groups (Young, Middle and Old).
3. Chi-Square Test: Checked whether there is an association between teachers' gender and tenure.
4. Pearson Correlation: Checked the relationship between teaching evaluation scores and beauty scores.
5. Created box plots, bar charts and scatter plots to understand the results visually.

**Results**

| Statistical Test | P-value | Result |
| T-Test | 0.001 | Significant difference |
| ANOVA | 0.000 | Significant difference |
| Chi-Square | 0.137 | No significant association |
| Pearson Correlation | 0.000 | Weak positive correlation |

 **Conclusion**
 
In this practical, I performed four statistical tests using Python. The T-test showed a significant difference in 
teaching evaluations between male and female teachers. ANOVA showed differences in beauty scores among age groups. 
The Chi-square test found no significant association between gender and tenure. Pearson correlation showed a weak 
positive relationship between beauty scores and teaching evaluations.
