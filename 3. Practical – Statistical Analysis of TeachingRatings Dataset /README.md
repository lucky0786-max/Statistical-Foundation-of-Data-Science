***Aim***

To analyze the Teachingratings dataset using Python and study the relationship between professors' age, gender, minority status and tenure.

***What I Did:***
- Loaded the dataset using Pandas.
- Checked the rows, columns and data types.
- Calculated the percentage of visible minority professors who are tenured.
- Calculated the mean and standard deviation of age for tenured and non-tenured professors.
- Created a histogram to compare age distribution by tenure.
- Created bar graphs to show gender distribution.
- Tried to calculate the median evaluation score of tenured professors.

***Conclusion:***

In this practical, I learned how to use Pandas and matplotlib to analyze data, calculate percentages, find statistical values and create graphs. I also learned how to compare professors based on age, gender and tenure status.
