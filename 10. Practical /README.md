### Aim
To analyse the Wine dataset using basic statistics, boxplot, scatterplot, 
covariance matrix, data scaling and Principal Component Analysis (PCA).

### What I Did
1. Loaded the Wine dataset using Scikit-learn.
2. Displayed basic statistics using `describe()`.
3. Created a boxplot to compare alcohol content across wine classes.
4. Created a scatterplot for alcohol and colour intensity.
5. Calculated and visualised the covariance matrix.
6. Scaled the data using `StandardScaler`.
7. Applied PCA to reduce 13 features into 2 principal components.
8. Created a scatterplot to visualise class separation.

### Conclusion
I learned how to analyse and visualise the Wine dataset using Python. PCA reduced the data to two 
components while retaining approximately **55.4% of the total variance**. This helped me understand 
data scaling, feature relationships and class separation.
