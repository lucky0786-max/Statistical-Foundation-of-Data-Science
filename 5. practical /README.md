**Aim**
To calculate probabilities using the TeachingRatings dataset and perform a Z-test to understand hypothesis testing in statistics.

**What I Did**
1. Loaded the TeachingRatings dataset using Pandas.
2. Calculated the probability of receiving a teaching evaluation score greater than 4.5.
3. Calculated the probability of receiving an evaluation score between 3.5 and 4.2.
4. Defined the null and alternative hypotheses for a Z-test.
5. Calculated the standard error, Z-score and p-value.
6. Compared the p-value with the 0.05 significance level to make a final decision.

**Conclusion**
In this practical, I learned how to calculate probabilities and perform hypothesis testing using Python.
The probability of scores greater than 4.5 was 17.06%, while the probability of scores between 3.5 and 4.2 was 35.42%. 
The Z-test gave a p-value of 0.156, which is greater than 0.05. Therefore, we failed to reject the null hypothesis, 
meaning there is no statistically significant difference from the historic mean.
